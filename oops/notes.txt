"""
    Instance Attributes: Instance attributes are created by the self keyword, and these attributes are define inside the constructor(__init__). Like self.name, self.age

    Class Attributes: Attributes are created without self keyword called class attributes, and these attributes save value for diff-2 object, if value change with object then this value is impact on the specific object.

    Instance Method: A method that created with self parameter, this method is called instance method.

    Class Method: Class method is created with the help of @classmethod decorator, and class method take the cls parameter.

    Satic Method: Method is created with @staticmethod decorator, and it is not depend on the   instance or class data, and not take the self or cls parameter.
    Static Method is used where we do not want to instance or cls data

    Without instance we can use it like:
        Classname.staticmethod

/Inheritance
"""
    Inheritance: A class that use the another class properties and method

    Type:
        1. Single level Inheritance
            class Class_2(Class_1) :
                pass

        2. Multiple Inheritance
            class Class_3(Class_1, Class_2):
                pass

        3. Multilevel Inheritance
            class class_2(Class_1)
                pass

            class class_3(class_2):
                pass

        4. Hierarchical Inheritance
            class Class_2(class_1):
                pass

            class Class_3(class_2):
                pass
"""

"""
    Encapsulation: Encapsulation mean binding the data inside a single unit like attributes and methods.
        Good example of the Encapsulation is class
        It is control the access of the attributes and method
        Basically we can access the data 3 access modifier types
            1. Public -> Access any where
            2. Protected -> Self class or child class (In python access any where)
            3. Private -> Only access inside class

            In Pythen Protected can define with single undeerscore, and Private can define with double undeerscore

            class A:
                # Public
                name = "Clg Name"
                # Protected
                _db = "xyz"
                # Private
                __DB_NAME = "ABC"
"""


"""
    Abstraction: Abstraction mean Hiding the unnecessary implementation details, only show the features to the user
        An abstract class must contain at least one abstract method.
        Child classes must implement it

        EX: 
            you use steering, brake, and accelerator
            you do not need to know the internal engine mechanism

        In python abc is a package, where we can get the abstractmethod
        from abc import ABC, abstractmethod
        class Vehicle(ABC):
            @abstractmethod
            def start(self):
                pass
"""
